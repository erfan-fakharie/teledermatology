# Demo patient profiles

Four fictional profiles for the existing demo users. No real patient identities, contact details, or clinical information were added. Profile metadata is in `src/lib/demo-patient-profiles.ts`; original account and case IDs are preserved. These are demo fixtures, not patient-editable database profiles.

Images were generated with the built-in Imagegen tool, with an opaque background. Original generated files were copied unchanged into the repository. Next.js Image serves sized versions for the UI.

## Saved assets and exact prompts

### patient_new

Asset: `public/demo-patients/patient_new.png`

Use case: photorealistic-natural. Asset: single square profile photograph for a fictional demo patient in a Persian medical app. A fictional Iranian woman aged 28, dark shoulder-length wavy hair, warm olive complexion, no eyewear, cream blouse, muted sage backdrop. Natural friendly expression, looking at camera, softly lit professional head-and-shoulders portrait, centered face occupying central 55 percent, ample margin around hair for circular avatar crop. Realistic skin texture, everyday person, no glamour retouching. Plain softly lit background. No text, no logos, no watermarks, one person only. Entire person must be fictional, not a known person.
