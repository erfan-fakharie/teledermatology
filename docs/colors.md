# رنگ‌های رابط mskin

رنگ‌های رابط در `src/app/style.css` تعریف شده‌اند و لندینگ هم از همین متغیرها استفاده می‌کند. رنگ ثابت لوگو و آیکون اپ در راهنمای برند نگهداری می‌شود.

| نقش | روشن | تیره |
| --- | --- | --- |
| زمینه | `#F5F6F2` | `#151B19` |
| کارت | `#FFFFFF` | `#1E2723` |
| سطح داخلی و زمینهٔ چت | `#F0F3EF` | `#19211D` |
| متن اصلی | `#25362D` | `#E6EEE8` |
| متن ثانویه | `#55675C` | `#A7B8AE` |
| اقدام اصلی و لینک | `#24644B` | `#92D5B0` |
| انتخاب و پیام خود کاربر | `#E8F1E9` | `#293D32` |

سبز برای هویت برند، اقدام اصلی و انتخاب استفاده می‌شود. وضعیت‌های عمومی آبی خاکستری، هشدارها کهربایی و خطاها قرمز ملایم هستند. برچسب «نسخهٔ نمایشی» خنثی است تا با هشدار اشتباه نشود. وضعیت‌ها همچنان متن دارند. پروندهٔ انتخاب‌شده علاوه بر زمینه، خط کناری دارد.

زمینهٔ نمایش عکس‌ها خنثی است؛ روی خود عکس‌ها فیلتر رنگ یا کاهش روشنایی اعمال نمی‌شود. مرز فیلدها از جداکنندهٔ کارت‌ها واضح‌تر است. حلقهٔ فوکوس در هر دو حالت رنگ متناسب با زمینه دارد.

## بررسی انجام‌شده

لندینگ، گالری و چت در هر دو حالت و چیدمان لندینگ در عرض‌های ۳۶۰ و ۱۴۴۰ پیکسل بررسی شدند. برای جفت‌رنگ‌های اصلی، متن ثانویه، دکمه و حالت hover، وضعیت‌ها و فوکوس محاسبهٔ کنتراست انجام شد.

| جفت‌رنگ | روشن | تیره |
| --- | --- | --- |
| متن اصلی / کارت | ۱۲٫۷۷ | ۱۲٫۹۷ |
| متن ثانویه / کارت | ۶٫۰۳ | ۷٫۳۸ |
| نوشته / دکمهٔ اصلی | ۷٫۰۰ | ۸٫۵۸ |
| متن ثانویه / زمینهٔ پیام خود کاربر | ۵٫۲۳ | ۵٫۵۹ |
| مرز فیلد / سطح فیلد | ۳٫۱۷ | ۳٫۹۹ |

نسبت‌ها برای رنگ‌های مشخص جدول محاسبه شده‌اند؛ به‌معنای ممیزی کامل دسترس‌پذیری همهٔ صفحات نیستند. ارزیابی زیبایی بصری با مشاهدهٔ صفحات انجام شده و آزمون استفادهٔ طولانی با پزشک یا بیمار انجام نشده است.
